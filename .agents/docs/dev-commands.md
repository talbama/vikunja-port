# Dev commands and configuration

- `mage -l` lists targets; `pnpm run` in `frontend/` lists scripts.
- `pnpm dev` serves the frontend on port 4173 (override with `VIKUNJA_FRONTEND_PORT` or `--port`).
- Scaffolding: `mage dev:make-migration <StructName>` (prompts if omitted), `dev:make-event`, `dev:make-listener`, `dev:make-notification`. `make-listener` also adds the `events.RegisterListener(...)` call; a listener only fires if registered there.
- Invoke the `migration` skill before touching `pkg/migration/`.
- Code generation: `mage generate:frontend-client` (v2 OpenAPI → `frontend/src/client/generated`, CI-checked by `mage check:frontend-client`), `mage generate:config-yaml false`, `mage generate:yaegi-symbols` and `mage generate:swagger-docs` (both regenerated by CI after merge; do not run unless asked), `mage generate:scalar-bundle`. Full target list: [.agents/wiki/components/build-and-release.md](../wiki/components/build-and-release.md).

## Configuration

`config.yml.sample` is generated from `config-raw.json` via `mage generate:config-yaml false`. Edit the JSON, then regenerate. The sample is gitignored, so a fresh clone has none until you generate it. Environment variables (`VIKUNJA_SECTION_KEY`) override config file settings. A minimal local `config.yml` is in [.agents/wiki/07-development-workflow.md](../wiki/07-development-workflow.md#configuration-for-local-runs).
